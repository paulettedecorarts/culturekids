public function impersonate(User $user) {
  $token = $user->createToken('impersonation', ['impersonated']);

  return response()->json(['token' => $token->plainTextToken]);
}

When API unavailable: Expo app detects offline via NetInfo → routes to expo-sqlite local DB → serves assets from Expo FileSystem (.ckb bundles) → queues writes to sync_queue table → on reconnect: POST /api/v1/sync drains queue → Laravel processes events, resolves conflicts by last-write-wins + server-authority.
Auth & Sanctum Token Flow
A1
Login — Sanctum Token Issue
Expo app sends POST /api/v1/auth/login { email, password }. Laravel validates credentials via Auth::attempt(). On success: Sanctum issues Personal Access Token with role abilities. Token stored in Expo SecureStore. Rate limited via Laravel Throttle middleware.
// AuthController.php
public function login(Request $request) {
  if (!Auth::attempt($request->only('email', 'password'))) {
    return response()->json(['error' => 'Unauthorized'], 401);
  }
  $user = Auth::user();
  $token = $user->createToken('expo-app', $user->getSanctumAbilities());
  return response()->json(['token' => $token->plainTextToken, 'user' => $user]);
}
A2
Sanctum Token Abilities + Laravel Policies
Every API route protected by auth:sanctum middleware. Laravel Policies enforce org-scoping: non-Super-Admin users can only access records where org_id matches their token's org. Spatie roles handle feature-level permission checks.
// routes/api.php
Route::middleware(['auth:sanctum'])->group(function() {
  Route::get('/tribes', [TribeController::class, 'index']);

});
// TribeController — org scoping
$tribes = Tribe::where('org_id', auth()->user()->org_id)->get();
A3
Web Session Auth — Blade (CSRF)
Laravel Blade web views use session-based auth (Sanctum stateful for web). CSRF token included in all Blade forms via @csrf directive. Cookie-based session managed by Laravel. Blade dashboard routes protected by auth middleware and role checks.

// database/migrations/create_progress_events_table.php
Schema::create('progress_events', function (Blueprint $table) {
  $table->id();
  $table->foreignId('child_id')->constrained('child_profiles')->cascadeOnDelete();
  $table->foreignId('comic_id')->nullable()->constrained('comics');
  $table->enum('event_type', ['story_start', 'story_complete', 'badge_earned', 'vocab_seen']);
  $table->string('idempotency_key', 64)->unique(); // prevents duplicate sync
  $table->json('payload')->nullable();
  $table->timestamp('synced_at')->nullable();
  $table->timestamps();
  $table->index(['child_id', 'event_type']); // composite index
});
